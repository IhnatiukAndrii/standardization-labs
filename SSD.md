# System Specification Document (SSD) — Інтернет-магазин дизайнерських годинників

## 1. Вступ
Цей документ описує системну специфікацію, архітектуру та технічні деталі вебдодатку «Інтернет-магазин дизайнерських годинників». Система призначена для демонстрації, пошуку, фільтрації та купівлі преміальних годинників, а також для адміністрування товарів, замовлень та новин.

---

## 2. Архітектура системи

Додаток побудований за сучасною трирівневою архітектурою (Client-Server-Database) з використанням монолітного підходу на базі фреймворку Next.js.

- **Frontend & Backend**: Next.js 15 (React 19, App Router, TypeScript).
- **Стилізація**: Vanilla CSS / CSS Modules.
- **База даних**: PostgreSQL (реляційна СКБД).
- **ORM**: Prisma ORM (для моделювання даних та міграцій).
- **Автентифікація**: NextAuth.js (Credentials Provider).
- **Контейнеризація**: Docker та Docker Compose (для локальної розробки та розгортання).

---

## 3. Схема бази даних (Data Models)

База даних спроектована з використанням Prisma ORM. Опис ключових сутностей та їхніх зв'язків:

- **User**: Зберігає дані користувачів. Має роль `USER` або `ADMIN`.
- **Product**: Товари (годинники) з ціною, описом, кількістю на складі та зв'язками з брендом і категорією.
- **Brand**: Бренди годинників (наприклад, Rolex, Casio).
- **Category**: Категорії (наприклад, Чоловічі, Жіночі, Спортивні).
- **CartItem**: Товари, які користувач додав у кошик. Має унікальний індекс по `(userId, productId)`.
- **Order & OrderItem**: Інформація про замовлення покупців, адреса доставки, телефон, статус замовлення (`PENDING`, `CONFIRMED`, `SHIPPED`, `DELIVERED`, `CANCELLED`).
- **Review**: Оцінки (від 1 до 5) та текстові відгуки користувачів про годинники.
- **News**: Новини та акції магазину.

---

## 4. Безпека та автентифікація

1. **Автентифікація**: Здійснюється через сесії NextAuth.js.
2. **Хешування паролів**: Паролі користувачів зберігаються в базі даних виключно в хешованому вигляді за допомогою бібліотеки `bcrypt`.
3. **Захист маршрутів API**:
   * Доступ до створення замовлень та кошика дозволений лише авторизованим користувачам.
   * Доступ до адмін-панелі та адмінських API (створення товарів, зміна статусів замовлень) дозволений лише користувачам з роллю `ADMIN`.

---

## 5. Вимоги до розгортання та конфігурації

Для запуску додатку необхідні змінні середовища (файл `.env`):
* `DATABASE_URL`: Рядок підключення до бази даних PostgreSQL.
* `NEXTAUTH_SECRET`: Секретний ключ для шифрування JWT/сесій NextAuth.
* `NEXTAUTH_URL`: Базова URL-адреса сайту (наприклад, `http://localhost:3000`).
